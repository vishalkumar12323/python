# Simple FastAPI

A minimal FastAPI comments API managed with `uv` and MongoDB.

## Run the server

Start MongoDB locally, then configure the connection with environment variables:

```bash
export MONGODB_URI=mongodb://localhost:27017
export MONGODB_DATABASE=comments
uv run uvicorn src.main:app --reload
```

The server runs at <http://127.0.0.1:8000>. These settings can also be placed in
a local `.env` file; do not commit credentials.

## Run with Docker Compose

Start the API and MongoDB together:

```bash
docker compose up --build
```

MongoDB data is stored in the `mongodb_data` named volume and survives container
restarts. To remove the database and all stored comments, run
`docker compose down --volumes`.

For deployments, set `MONGODB_URI` to a MongoDB connection string with
authentication and TLS as appropriate, and set `MONGODB_DATABASE` to the
database name. Keep credentials in the deployment's secret manager rather than
in source control.

## Endpoints

- `GET /api/healthz` returns `{"status": "ok", "message": "API status is healthy 🌐"}`.
- `GET /api/v1/comments?limit=100&offset=0` lists comments; `limit` is between 1 and 500.
- `GET /api/v1/comment/{comment_id}` gets one comment.
- `POST /api/v1/create-comment` creates a comment from `{"comment": "Your comment"}`.
- `PUT /api/v1/update-comment/{comment_id}` updates a comment from `{"comment": "Updated comment"}`.
- `DELETE /api/v1/delete-comment/{comment_id}` deletes a comment.

Comment IDs are generated by MongoDB and returned as strings. Unknown or invalid
IDs return `404`.

Interactive API documentation is available at <http://127.0.0.1:8000/docs>.
